# Global section animation comparison

`section-opening.mp4` compares the four production presets with the same category component, catalog images, viewport, intensity and timing. Frames are rendered from `StorefrontStory` and `CategoriasSection` using their native browser animations at 25 fps, followed by an 0.8-second hold.

- `stack`: Pop-up escultórico — objects unfold from their own base in 3D.
- `cinema`: Iris de enfoque — circular apertures reveal stationary content.
- `depth`: Trama de imágenes — cropped strips of static cards weave together; players use a striped aperture without cloning media.
- `cascade`: Enfoque cinematográfico — macro framing and rack focus resolve into the natural layout.

Preset identifiers and existing saved settings remain compatible. There are no added covers or blank opening panels. Desktop and mobile previews in the administration panel use the same production engine; the automatic preview pauses at each section so its sequence can finish.
